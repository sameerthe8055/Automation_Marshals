## 📖 Project Description
**AnyLangTranslate** is a UiPath-based automation project designed to translate text from any language to a specified target language in real time. The bot also generates a detailed summary report of all the translations performed during the session.

This project was developed as part of the *UiPath Hack-a-Bot* competition, where it won **1st Prize** for its efficiency, teamwork, and presentation excellence.
